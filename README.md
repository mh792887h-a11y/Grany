# 🏚️ بَيْتُ العَجُوزْ | The Granny's House Horror Game

لعبة رعب ثلاثية الأبعاد كاملة، مستوحاة من أسلوب لعبة **جراني (Granny)** الشهيرة بواجهة عربية متكاملة، ونظام ذكاء اصطناعي يسمع حركات اللاعب، وأماكن اختباء وألغاز هروب، ومؤثرات صوتية رعب فورية بواسطة Web Audio API.

---

## 🎮 تجربة اللعبة والتشغيل السريع (Quick Start)

### 1. التشغيل المحلي على جهازك (Local Development):
تأكد من تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)، ثم نفّذ الأوامر التالية:

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على الرابط: `http://localhost:3000`

---

### 2. البناء للإنتاج (Production Build):
```bash
# بناء المشروع داخل مجلد dist
npm run build

# معاينة البناء
npm run preview
```

---

### 3. النشر المباشر والتجربة على GitHub Pages مجاناً:
تم إعداد ملف **GitHub Actions** تلقائياً في `.github/workflows/deploy.yml`. لتفعيل الرابط المباشر للعبة على حسابك في GitHub:
1. ارفع المشروع إلى مستودعك في GitHub (`git push origin main`).
2. افتح صفحة المستودع على GitHub، ثم اضغط على **Settings**.
3. من القائمة الجانبية، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - غيّر **Source** من `Deploy from a branch` إلى **`GitHub Actions`**.
5. سيبدأ البناء تلقائياً في تبويب **Actions**، وستحصل على رابط اللعبة المباشر لتجربتها ومشاركتها مع أصدقائك!

## 🕹️ أزرار التحكم (Controls):

| الزر | الوظيفة |
| :--- | :--- |
| **W, A, S, D** أو **الأسهم** | الحركة والمشي في أرجاء المنزل |
| **Shift** | الجري السريع (⚠️ حذار! يصدر صوتاً عالياً تسمعه العجوز) |
| **C** | القرفصاء والتسلل بهدوء (خطوات صامتة والزحف تحت السرير) |
| **E** | التفاعل (التقاط الأدوات، فك الأقفال، الاختباء داخل الخزانة) |
| **Q** | إسقاط الأداة التي بيدك (مفيدة لتشتيت العجوز بمصدر صوت بعيد) |
| **F** | تشغيل / إطفاء المصباح اليدوي |
| **Esc** | إيقاف اللعبة مؤقتاً (Pause) |
| **الهاتف / الجوال** | دعم كامل للمس مع عصا تحكم افتراضية وسحب لتوجيه النظر وأزرار تفاعل سريعة |

## 🔑 أسرار الهروب وقواعد النجاة:
- أمامك **5 أيام فقط** للهروب من البيت الملعون!
- الباب الرئيسي مقفل بـ 3 أقفال أمان:
  1. **اللوح الخشبي**: تجد **العتلة الحديدية** في طاولة المطبخ لخلعه.
  2. **القفل المعدني الثقيل**: تجد **مفتاح القفل الأزرق** في غرفة النوم.
  3. **لوحة المفاتيح الرقمية**: تجد **قصاصة الرمز السري** على صناديق غرفة التخزين.
- تجنب إسقاط المزهريات الخزفية أو الجري بالقرب من العجوز حتى لا تكتشف مكانك.
- عند اقتراب العجوز، اختبئ فوراً داخل الخزانة أو تحت السرير حتى تبتعد!
